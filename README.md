### How I work

Integration is the actual skill. I'm not a single-stack specialist. What I'm good at is
making complex systems work together, technically and organizationally, which means I've
sat in most of the seats: auditor, developer advocate, designer, sales partner, optimizer,
ops manager, analyst, owner, and the user on both sides of the product.

In the repos above that tends to show up as strong domain models, separation of concerns,
opinionated structure without over-engineering, and docs that explain why rather than only
how. I build things for real adoption, not for demos.
